CLI search tools, engine by engine

For every free search engine in the rotation, what can an agent on Ubuntu actually call from the terminal today — officially, for free, and without a payment card? The honest answer is narrower than the list of engines: two clean routes, a few card-gated ones, and several doors that have already closed.

Bottom line

If you want a legitimate free CLI route today, start with Tavily for general web search and Marginalia for the non-commercial web. Everything else either asks for a card before the “free” part starts, survives only as a scraper the engine actively blocks, or no longer exists.

Bot-block behaviour (403 / 429 / captcha) is IP- and time-dependent. The figures below rest on published live tests from July–October 2026 and vendor pages checked 8 Nov 2026 — not on a fresh test in this run.

Cross-cutting: self-hosted SearXNG — free infrastructure, grey upstreams

SearXNG is not a CLI. It's an open-source metasearch service you host yourself (Docker), aggregating 70+ engines — the free fallback that fills the same tool slots for Bing, DuckDuckGo, Google, Ecosia and Startpage. Enable json in settings.yml (otherwise JSON requests get 403), then query it with curl 'http://localhost:8080/search?q=…&format=json'.

Cost & footprint: free, no key, no apt package. RAM is 256 MB minimum, 512 MB recommended, plus 50–100 MB for Valkey/Redis — confirming the ~150–300 MB ballpark at the low end. Public instances usually disable JSON, so self-hosting is the reliable path — and it inherits the blocking behaviour of whatever engines it scrapes.

Sources — index selfhosting.sh/apps/searxng · railway.com/deploy/searxng-search-api · bitdoze.com/searxng-self-host-privacy-search

01 · HOSTED DEVELOPER SEARCH

Tavily & the hosted APIs

The category behind most agent-framework web_search tools — Tavily is the headline example. Serper and SerpApi sit in the same slot.

✅ Usable free today
Verdict: The cleanest legitimate free route in this whole report. Official API, free key, no card — 1,000 credits a month, hard stop at zero.
Tool / method
Tavily REST API (api.tavily.com) via curl or pip SDK tavily-python. Wrappers: eggsearch (single Rust binary, MCP + CLI), ketch, Hermes web_search.
Official or grey?
Official / sanctioned — the vendor's own product, not a scrape. Serper/SerpApi are sanctioned by the vendor you pay, but grey upstream (they obtain Google results Google offers no API for).
Free tier
Tavily Researcher: 1,000 credits/month, no credit card. Basic search = 1 credit, advanced = 2. Alternatives: Serper 2,500 free queries one-time, no card; SerpApi 250 searches/month free.
Packaging
No apt package. pip SDKs / plain curl. eggsearch is a standalone Rust binary (GitHub / cargo).
Terminal — Tavily
pip install tavily-python

# Or plain curl — key from a free signup, no card
curl -X POST https://api.tavily.com/search \
  -H "Authorization: Bearer $TAVILY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "your search terms", "max_results": 5}'

Watch-out: Google sued SerpApi in Dec 2025 over anti-bot circumvention; the case was unresolved as of Aug 2026. That continuity/legal risk belongs to the SERP-API route, not to Tavily itself — but it's why “vendor-sanctioned” and “upstream-legitimate” are kept separate here.

Sources Tavily pricing — verified live 2026-11-08 — tavily.com/pricing · Serper free grant (index) — keirolabs.cloud/blog/serper-api-guide-2026 · parallel.ai/articles/best-free-web-search-api (vendor pages checked 27 Oct 2026)

02 · MICROSOFT

Bing

The official results API existed for years — and was retired completely. What replaced it returns answers, not results.

❌ Not usable free
Verdict: No official Bing results API exists any more. Only paid Azure grounding (answers, not results) or grey, captcha-prone scraping of bing.com.
Tool / method
Formerly Bing Web Search API v7 via Azure. Successor: Grounding with Bing Search in Azure AI Foundry / AI Agents. Grey fallback: SearXNG's bing engine, openserp, SERP APIs.
Official or grey?
The old API was official — and is dead. Grounding is official but Microsoft states developers/end users have no access to the raw content returned; you get an LLM answer with citations.
Free tier
None. Retirement covered every tier (F1/S1–S9, Custom F0/S1–S4); endpoints return HTTP 410 Gone, no new keys. Grounding is paid Azure only — $14 per 1,000 transactions per Microsoft's Sept 2026 listing, plus model costs. Free-credit Azure subscriptions don't qualify.
Packaging
Azure SDKs (pip azure-ai-*). No apt CLI for Bing search.

Price caveat: Some Oct 2026 secondary reads still cite $35/1,000 for Grounding. Treat the price as in flux — either way it's paid-Azure-only with no free tier, so the verdict is unaffected.

Sources — index, quoting Microsoft Learn searxncrawl.io/bing-google-search-api-alternative · fe.tonywang.io/blog/bing-search-api-alternatives · serplify.io/blog/bing-search-api-alternatives — “Bing Search APIs will be retired on August 11, 2025… decommissioned completely”

03 · PRIVACY SEARCH

DuckDuckGo

Two tools everyone reaches for — ddgr and ddgs — and one official API that isn't actually web search.

⚠️ Grey only for results
Verdict: Works free at low volume from a residential IP via ddgr/ddgs, unreliable under automation. The only official API (Instant Answers) does not return search results.
Tool / method
ddgr (CLI, scrapes the HTML version), ddgs (pip library + CLI, formerly duckduckgo_search), and the official Instant Answer API at api.duckduckgo.com.
Official or grey?
ddgr/ddgs are grey scrapers — ddgr states it “isn't affiliated to DuckDuckGo in any way”; DDG's terms prohibit scraping. Instant Answer API is official but returns a Wikipedia-style abstract for entity queries, empty for most others.
Free tier
All free, no key, no card, no published limits. In practice: ddgs raises RatelimitException: 202, bursts and datacenter/VPN IPs are throttled almost immediately, and the HTML endpoint serves bot-check pages. ~1 req/s is the community-safe pace.
Packaging
✅ ddgr in apt — Ubuntu noble ddgr 2.2-1 [universe], also snap and standalone .deb. ddgs via pip only.
Terminal — DuckDuckGo (grey)
sudo apt install ddgr
ddgr "your search terms"

# pip alternative
pip install ddgs
ddgs text -q "your search terms"

# Official — but abstracts only, NOT web results
curl "https://api.duckduckgo.com/?q=ubuntu&format=json"

Sources — index packages.ubuntu.com/eu/noble/misc · browserfoundry.cloud/blog/duckduckgo-search-api · link.sc/blog/duckduckgo-search-api-guide · keirolabs.cloud/blog/duckduckgo-search-api

04 · INDEPENDENT INDEX

Brave Search

A real official API over Brave's own 30B+ page index — whose free plan quietly became a card-gated credit in February 2026.

⚠️ Legitimate, not card-free
Verdict: If a card on file is acceptable, ~1,000 free official queries/month. If “free” means no card, Brave no longer qualifies. The grey scrape rate-limits hard (429).
Tool / method
Brave Search API — GET api.search.brave.com/res/v1/web/search with header X-Subscription-Token, via curl, community SDKs, or Brave's official MCP server (npm @brave/brave-search-mcp-server).
Official or grey?
API is official. Scraping search.brave.com (SearXNG / eggsearch engines) is grey.
Free tier
Old free plan (2,000/mo, later 5,000) ended Feb 2026. Now: Search at $5 per 1,000 requests with $5 in free credits every month (≈1,000 requests), 50 req/s. A credit card is required to activate any plan, including to use the free credits (anti-fraud), and attribution is required to keep the credit.
Packaging
No apt/pip first-party CLI; curl or the npm MCP server.
Terminal — Brave Search API
curl -H "Accept: application/json" \
  -H "X-Subscription-Token: $BRAVE_API_KEY" \
  "https://api.search.brave.com/res/v1/web/search?q=your+search+terms"

Consumer-page behaviour: In a Jul 2026 live test series, Brave's rendered results page was the one consumer channel that worked — then returned persistent HTTP 429s that ~20 minutes of paced retries never cleared.

Sources Official pricing (index) — api-dashboard.search.brave.com/documentation/pricing · Card/credit corroboration — apiserpent.com/blog/free-brave-search-api (Brave's own pages, 23 Oct 2026) · scrapegraphai.com/blog/brave-search-api · 429 live test — github.com/directiveforge/directiveforge

05 · THE BIG INDEX

Google

googler is sitting in apt right now — and Google's defences are exactly why being packaged doesn't mean working.

⚠️ Grey only — no legitimate new route
Verdict: Grey googler is in apt but unreliable against current defences — there is no legitimate new route. The practical free-ish Google route is a third-party SERP API trial (Serper: 2,500 one-time, no card — vendor-sanctioned, grey upstream).
Tool / method
googler (CLI scraper), Custom Search JSON API (Programmable Search Engine), third-party SERP APIs (§1), SearXNG's google engine.
Official or grey?
googler is a grey scraper; Google's terms prohibit automated access and robots.txt disallows /search. Custom Search was official but returned results from a configured engine, not google.com as such.
Free tier / status
Custom Search is closed to new customers (new keys fail, 403 reported; new engines since 20 Jan 2026 limited to ≤50 sites). Existing customers keep 100 free/day, then $5/1,000, cap 10,000/day — only until discontinuation on 1 January 2027.
Packaging
✅ googler in apt — googler 4.3.13-1 [universe] (Ubuntu questing; also Debian bookworm), plus a standalone GitHub script.
Terminal — Google (grey, expect breakage)
sudo apt install googler
googler "your search terms"
# Since Jan 2025 Google requires JavaScript to serve results —
# plain HTTP often gets a JS shell, consent page, or 429.

Raw-page fetching: Confirmed hostile — plain HTTP gets a JS shell, consent interstitial, or “unusual traffic” page (sometimes HTTP 200, sometimes 429), so googler-style parsing frequently returns zero results, especially from datacenter IPs. Google's suggested replacements (Vertex / Agent Search) are site-restricted to 50 domains, not full-web search.

Sources — index cloro.dev/blog/google-search-api · browserfoundry.cloud/blog/google-custom-search-api-alternative · packages.ubuntu.com/fi/questing/misc · webscraping.ai/blog/scrape-google-search-results

06 · INDEPENDENT INDEX

Mojeek

An official API over Mojeek's own ~9B-page index — gated behind a bank card before the free credit even starts.

❌ No ongoing free tier
Verdict: The API exists and is legit, but free use is a one-off trial credit behind a bank card. The consumer page 403s / captchas automated callers.
Tool / method
Mojeek Search API (official, JSON/XML, curl with API key). Grey: scraping mojeek.com/search (eggsearch / SearXNG engines).
Official or grey?
API is official. HTML scraping is grey — and blocked.
Free tier
No recurring free tier. Mojeek's own FAQ: sign up to the Startup Plan and claim a free credit — but “a bank card is required to open an account” (no automatic payments, via Stripe). Paid PAYG thereafter: Startup ≈£2 per 1,000 queries in the Jul 2026 live read.
Packaging
No apt/pip CLI; API key + curl.

HTML behaviour & price caveat: Bare request → HTTP 403; with a browser user-agent → HTTP 200 serving an ALTCHA/captcha challenge, not results. A Personal tier at £1/1,000 is cited elsewhere — check Mojeek's live pricing page before relying on the exact tier ladder; the card-required fact comes from Mojeek's own FAQ and is solid.

Sources Official (index) — mojeek.com/services/search/web-search-api · Live block test — github.com/katrielmoses/mailaccess

07 · TREE-PLANTING SEARCH

Ecosia

No developer API was found at all — and the consumer page is behind Cloudflare with a consistent 403 for automated callers.

❌ No route at all
Verdict: No official API and the consumer page 403s automated callers. Do not build on Ecosia scraping.
Tool / method
No named CLI and no public developer search API found. Grey only: SearXNG's ecosia engine, openserp (browser-rendered), eggsearch-style scrapers.
Official or grey?
Grey only. Historically Bing/Google-backed; since Aug 2025 partly its own EUSP/Staan index in France/Germany — Staan is B2B partner infrastructure with no free public developer API, key signup, or pricing documented in any source found.
Free tier
N/A — no API to have one.
Packaging
None.

HTML behaviour: HTTP 403 in repeated live tests (Jul 2026 federation test: 403 on every attempt; another test: loaded JS-empty, then 403 on retry).

Sources — index github.com/katrielmoses/mailaccess · Staan background — ppc.land/ecosia-launches-european-search-index-in-france

08 · PRIVACY FRONT-END

Startpage

A privacy relay to Google and Bing with no index of its own — and an anti-abuse system built specifically to stop people doing this.

❌ No reliable route
Verdict: No legitimate programmatic route exists, and grey scraping is specifically targeted by Startpage's anti-abuse system.
Tool / method
No official API or CLI. Grey scrapers only: SearXNG's startpage engine, eggsearch's vendored Startpage HTML scraper.
Official or grey?
Grey only. Startpage relays queries to Google and Bing and actively defends against automation (“subjected to automated abuse and scraping on a daily basis… strong anti-abuse measures”), including captcha and, per one survey, a proof-of-work challenge.
Free tier
N/A — no API.
Packaging
None.

In live tests: “Flatly refused” in the Jul 2026 cross-engine test series; other tooling documents captcha-detection as a routine Startpage failure mode.

Sources — index searchengines.net/startpage · fe.tonywang.io/docs/startpage · github.com/directiveforge/directiveforge

09 · SMALL INDEPENDENT INDEX

Marginalia Search

The surprise of the list: a documented official API whose shared key is literally the word public. No signup. Just curl.

✅ Usable free today
Verdict: The only engine-native, keyless, card-free official API in this list. Expect 503s on the shared key at busy times — and niche coverage.
Tool / method
Official public API — plain curl. New: GET api2.marginalia-search.com/search with header API-Key: public. Old API (api.marginalia.nu/public/…) is deprecated. Also via SearXNG.
Official or grey?
Official / sanctioned — Marginalia's documented developer API. Results licensed CC-BY-NC-SA 4.0 (non-commercial; commercial use needs a commercial key by email).
Free tier
No signup, no card. The shared key public works immediately but often hits a rate limit (new API) / returns HTTP 503 when the shared limit is hit (old API), and can't use custom filters. A free personal key is available by emailing contact@marginalia-search.com.
Packaging
Nothing to install — curl on any Ubuntu box; optionally SearXNG via Docker.
Terminal — Marginalia (official, keyless)
curl -H "API-Key: public" \
  "https://api2.marginalia-search.com/search?query=your+search+terms"

Coverage caveat: Marginalia deliberately indexes the non-commercial, text-heavy web — personal sites, blogs, wikis, forums. It's weak or absent for news, commerce and mainstream topics (it does not index Reddit at all in tests). A complement, not a Google replacement.

Source — verified live 2026-11-08 about.marginalia-search.com/article/api

10 · AI ANSWER ENGINE

Google Gemini with search grounding

Google's sanctioned replacement story: a model-written answer with citations — not a raw results list, and not free-tier eligible.

⚠️ Only with billing on
Verdict: Official and excellent for grounded answers, but NOT free from a terminal without enabling billing (card). With billing on, 5,000 grounded searches/month are included before the $14/1,000 rate.
Tool / method
Gemini API with the google_search tool — curl to the Gemini Developer API, pip google-genai SDK, or Google's gemini CLI. Key from Google AI Studio.
Official or grey?
Official.
Free tier — the catch
For Gemini 3 and newer, grounding is NOT on the API Free Tier: calls from a project without billing return HTTP 429, and Google's pricing page lists grounding as “Not available” in the Free Tier column. Billing-enabled projects get 5,000 free search requests/month (shared, daily cap 1,500/day), then $14/1,000 — plus per-token charges; one prompt can trigger several billable searches.
Packaging
pip (google-genai) / npm (@google/gemini-cli) / curl. No apt package.
Terminal — Gemini grounding, Route A: pip SDK
# Route A — Python SDK (pip). Enable billing first:
# without it, grounded calls on Gemini 3+ return HTTP 429.
pip install google-genai

python3 - <<'PY'
from google import genai
from google.genai import types
client = genai.Client()  # uses GEMINI_API_KEY
resp = client.models.generate_content(
    model="your-gemini-3-model",
    contents="Your question",
    config=types.GenerateContentConfig(
        tools=[types.Tool(google_search=types.GoogleSearch())]))
print(resp.text)
PY
Terminal — Gemini grounding, Route B: Gemini CLI (npm)
# Route B — the separate Gemini CLI (npm, NOT the pip SDK)
npm install -g @google/gemini-cli
gemini "Answer with live web grounding: your question"

Legacy exception & source conflict: Gemini 2.5 Flash/Flash-Lite pricing lists 500 grounded requests/day free — but new users report 2.5 models returning 404 / “no longer available to new users”, so don't plan on it. Several Oct 2026 summaries say “5,000 free/month” without the billing gate; Google's own staff clarification and the pricing page's Free-Tier column resolve it — the 5,000 are free on a billing-enabled project. Grounding is free to try interactively in AI Studio's web UI, which is not a CLI route.

Sources — index Google staff reply — discuss.ai.google.dev/t/google-search-grounding/191945 · Google pricing via aistudio.google.com/docs/pricing · Corroboration — infro.io/blog/gemini-api-pricing-2026

11 · AI CHAT

Duck.ai

DuckDuckGo's AI chat is free in a browser — and has no public API. Every bridge to it is reverse-engineered.

❌ No legitimate route
Verdict: No legitimate CLI/programmatic route exists. Unofficial browser-driving bridges work until they break or get the IP banned; do not build an agent on them.
Tool / method
No official tool. Unofficial bridges only (duckapi / DuckAI2API) exposing an OpenAI-compatible endpoint by driving the real duck.ai site in Chrome via Playwright or reverse-engineering its protocol (anti-bot tokens such as x-fe-signals / vqd).
Official or grey?
Grey / reverse-engineered. The bridge projects themselves state: “Duck.ai has no public API”, and warn use may violate Duck.ai's terms. The closest official DuckDuckGo surface remains the Instant Answers API (§3) — a different, non-chat, non-search product.
Free tier
Duck.ai itself is free/anonymous in a browser with a daily usage limit (resets midnight UTC; exact count unpublished, varies by model) — with no sanctioned programmatic way to consume it. Bridges risk a persistent per-IP ban: HTTP 418 ERR_BN_LIMIT, no Retry-After.
Packaging
GitHub clones / pip installs of unofficial projects only. Nothing in apt, nothing official on pip/npm.

Open verification point: Multiple sources confirm DuckDuckGo's only developer API is Instant Answers and that Duck.ai has no API — but no primary DuckDuckGo help page was found that explicitly directs Duck.ai developers to the Instant Answers API. Treat that specific wording as plausible but not primary-source-verified.

Sources — index github.com/hirotomasato/duckapi · github.com/wuyouseo/DuckAI2API · github.com/emahboubinia/duckai-openai-api

Open questions

What the research could not settle — stated plainly, not filled in.

  • Which hosted backend is “the” one? The original ask named no single vendor for the hosted developer-search category. Tavily is reported as the archetype; Exa, Parallel, Firecrawl and Keenable sit in the same category with differing no-card free allowances that would need a re-check if one specific backend was meant.
  • Duck.ai → Instant Answers wording: confirmed that Instant Answers is DuckDuckGo's only developer API and Duck.ai has none — but no primary DuckDuckGo page explicitly redirecting Duck.ai developers to it was located.
  • Bing Grounding price: $14/1,000 (Sept 2026 Microsoft-derived listings) vs $35/1,000 (older/other reads). Paid either way; verdict unaffected.
  • Mojeek tier ladder: £1/1,000 “Personal” vs £2/1,000 “Startup” appears inconsistently across sources. The card-required free-credit fact is from Mojeek's own FAQ and is solid.
  • Bot-block behaviour is a moving target: DDG captcha, Brave 429, Mojeek/Ecosia 403 and Google unusual-traffic outcomes are IP- and time-dependent, drawn from published Jul–Oct 2026 live tests.

What to actually install

For a working free setup today: sign up for a Tavily key (no card) for general web search, use Marginalia's public key for the independent web, and keep ddgr from apt as a low-volume DuckDuckGo fallback — paced at ~1 request/second, with the understanding that it's a grey scraper that can captcha at any time. Add self-hosted SearXNG (512 MB RAM) only if running a small Docker service is acceptable. Skip Ecosia, Startpage and Duck.ai entirely for programmatic use, and don't plan around Bing or Google Custom Search — both are gone for new users.
