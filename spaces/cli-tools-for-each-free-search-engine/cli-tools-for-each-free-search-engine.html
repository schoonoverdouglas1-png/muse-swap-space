Start here — the three that actually work for free

If you install nothing else, install these. They are the only sanctioned, no-card paths to real web results from a Linux terminal today.

✅ Best general web · Official · Pending sign-up

1 · Tavily

1,000 API credits/month, no credit card required — requests hard-stop at zero. Basic search = 1 credit, advanced = 2. Called with curl to api.tavily.com or the pip SDK tavily-python. No apt package. Status on Ember’s box: pending your sign-up decision — not yet obtained.

pip install tavily-python # or plain curl — see terminal above

Source: Tavily pricing, verified live 2026-11-08 — tavily.com/pricing

✅ Keyless · Official · Nothing to install

2 · Marginalia Search

Official public API with the shared key literally public — just curl. Heavily rate-limited (HTTP 503 when the shared limit is hit) and a small, non-commercial index: strong on personal sites, blogs, wikis and forums; weak or absent for news and commerce, and it does not index Reddit in tests. Results are CC-BY-NC-SA 4.0. A free personal key is available by emailing contact@marginalia-search.com.

curl "https://api2.marginalia-search.com/search?query=…" \ -H "API-Key: public"

Source: Marginalia API docs, verified live 2026-11-08 — about.marginalia-search.com/article/api

✅ Free forever · You run it · Grey upstreams

3 · SearXNG (self-hosted)

Open-source metasearch aggregating 70+ engines. Not a CLI — a Docker service you run: 256 MB RAM minimum, 512 MB recommended, +50–100 MB for Valkey/Redis. Enable json in settings.yml (otherwise JSON requests get 403), then query it locally. Free, no key, no apt package. Caveat: upstream it still scrapes engines, so several engines block it — and public instances usually disable JSON, so self-hosting is the reliable path.

curl "http://localhost:8080/search?q=…&format=json"

Sources: selfhosting.sh/apps/searxng · railway.com/deploy/searxng-search-api · bitdoze.com

Integrating through Ubuntu’s own repository interface

This was the second half of your ask — can the engines come in through apt itself? Partly. Only two search tools live in the Ubuntu repositories, and both are grey scrapers. Everything official arrives by pip, npm, curl, or Docker — there is no apt package for any official search API.

1

Enable Universe, install the two apt tools

ddgr 2.2-1 [universe] (Ubuntu noble) for DuckDuckGo and googler 4.3.13-1 [universe] (Ubuntu questing listing) for Google are real apt packages — packaging exists even though the upstream services block the technique. Both scrape the consumer results page; neither is sanctioned.

sudo add-apt-repository universe sudo apt update sudo apt install ddgr googler
2

Add the pip layer for the official APIs

Tavily (tavily-python), DuckDuckGo’s library form (ddgs, pip only, formerly duckduckgo_search), and Gemini (google-genai) all install via pip. Serper, Brave and Mojeek need no install at all — just curl with a key header.

pip install tavily-python ddgs google-genai
3

Run SearXNG as your local metasearch service

Docker is the deployment route (Docker image / pip; no apt package). Budget 512 MB RAM in typical Docker Compose guidance — the report confirms the ~150–300 MB ballpark only at the very low end (256 MB minimum). Turn on the json format in settings.yml or your agents will get 403s.

# after starting the SearXNG container on :8080 curl "http://localhost:8080/search?q=test&format=json"
4

Ask an AI to search for you

Two sanctioned shapes exist, and they are not the same product. Tavily / Serper / SerpApi return a results list an agent can read. Gemini with the google_search tool returns a model-written answer with citations — not raw results — and for Gemini 3+ it is not available on the API Free Tier: without billing enabled, calls return HTTP 429. With billing on, 5,000 grounded searches/month are included, then $14 per 1,000, plus token charges. Agent wrappers in this slot include eggsearch (single Rust binary, MCP + CLI), ketch, and Hermes Agent’s web_search.

pip install google-genai # Gemini grounding npm i @google/gemini-cli # or the gemini CLI
Watch the upstream risk on Google results: Serper (2,500 free queries, one-time, no card) and SerpApi (250 searches/month free) are sanctioned by the vendor you pay — but upstream they obtain Google results Google does not offer via an official API. Google sued SerpApi in Dec 2025 over anti-bot circumvention; the case was unresolved as of Aug 2026. Treat that whole route as grey upstream, with continuity risk.

§10Gemini + Search grounding

⚠️ Billing required

Best method: Gemini API with the google_search tool — via curl, pip google-genai, or Google’s gemini CLI, key from Google AI Studio. Returns a model-written answer with citations, not a raw results list.

Official?
✅ Official — Google’s sanctioned replacement story for programmatic Google-grounded answers
Key?
Yes
Card?
Yes — billing must be enabled on the project
Free limit
For Gemini 3+: grounding is “Not available” on the Free Tier — no-billing calls return HTTP 429 (Google staff reply, Oct/Nov 2026). Billing-enabled projects: 5,000 free search requests/month (shared across Gemini 3+ models, daily cap 1,500/day), then $14/1,000 + token charges; one prompt can trigger several billable queries

§11Duck.ai (DuckDuckGo AI chat)

❌ No API

Best method: None legitimate. Unofficial bridges only — e.g. duckapi / DuckAI2API projects exposing an OpenAI-compatible endpoint by driving the real duck.ai site in Chrome via Playwright or reverse-engineering its XHR/SSE protocol (anti-bot tokens such as x-fe-signals / X-Vqd-Hash-1 / vqd).

Official?
❌ Grey / reverse-engineered. The bridge projects themselves state: “Duck.ai has no public API” — and warn use may violate Duck.ai’s terms
Free limit
Duck.ai is free/anonymous in a browser with a daily usage limit (resetting midnight UTC, exact count unpublished) — but there is no sanctioned programmatic way to consume it
Risk
Bridges risk a persistent per-IP ban: HTTP 418 ERR_BN_LIMIT with no Retry-After/cooldown
Packaging
GitHub clones / pip installs of unofficial projects only; nothing in apt, nothing official on pip/npm
VerdictDo not build an agent on the unofficial bridges — they work until they break or get the IP banned.

Open questions — stated plainly

Things the research could not settle. Nothing here is guessed.

  • Which hosted service is “the” one? The original ask named no single vendor for the hosted developer-search category. Tavily is reported as the archetype — if you meant one specific backend (e.g. behind a particular agent framework’s web_search tool), its numbers should be re-checked: Exa, Parallel, Firecrawl and Keenable all have differing no-card free allowances in the same category.
  • Duck.ai → Instant Answers redirection: Multiple sources confirm Instant Answers is DuckDuckGo’s only developer API and Duck.ai has none — but no primary DuckDuckGo help page was found that explicitly directs Duck.ai developers to the Instant Answers API. Treat that specific wording as plausible, not primary-source-verified.
  • Bing Grounding price conflict: $14/1,000 (Sept 2026 Microsoft-derived listings) vs $35/1,000 (older/other reads). Either way it is paid-Azure-only with no free tier, so the verdict is unaffected.
  • Mojeek tier ladder: £1/1,000 “Personal” vs £2/1,000 “Startup” appears inconsistently across sources. The card-required free-credit fact comes from Mojeek’s own FAQ and is solid.
  • Bot-block behaviour is IP- and time-dependent (DDG captcha, Brave 429, Mojeek/Ecosia 403, Google unusual-traffic). The figures above come from published Jul–Oct 2026 live tests, not a fresh test in this run.
  • ddgr PPA currency: Whether the ddgr PPA ppa:twodopeshaggy/jarun still publishes Noble (24.04) builds could not be verified — only 2017-era articles cite it; Launchpad was not opened.
  • Cargo crates’ direct URLs: Direct crates.io URLs for hodis, duckduckgo-search-cli, and web-search could not be verified — the search tool did not return verbatim URLs for those listings (it suppressed some result URLs), so they are named without links rather than with reconstructed URLs. Their existence and cargo install commands come from index snippets.
  • Marginalia add-on on Android: Whether the NUH “Marginalia Search” Firefox add-on installs / works on Firefox for Android specifically could not be verified — its AMO page does not state Android compatibility in the fetched text.
  • Flathub / Snap storefronts not live-checked: Flathub / Snap storefront pages could not be checked in the live research browser (window returned page_gone); Brave / Newelle store claims rest on the vendors’ own pages plus index fetches of the store listings, which agree with each other.
Bottom line for your backend: wire Tavily as the general-web default (free key, 1,000/mo), Marginalia as the zero-setup fallback (API-Key: public), and SearXNG in Docker as the keyless metasearch layer — accepting that its upstreams are grey. Add Brave or Gemini grounding only if a card on file is acceptable. Don’t build on Bing, Ecosia, Startpage, or Duck.ai programmatic access: there is none. And on integration: install Tavily via PyPI (tavily-cli / tavily-python) or npm, Brave via its vendor apt repo — and don’t wait for an official Tavily or Marginalia desktop GUI, Android app, or GNOME provider: the maximum-research pass found none exists. The working substitutes are Newelle (Flathub, calls Tavily), WM Keyboard on Android (your own Tavily key), the Marginalia Firefox add-on, and — for OS-level search on 24.04 — Epiphany’s Web provider or a third-party Google / DuckDuckGo extension.
